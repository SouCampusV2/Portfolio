# Sync Portfolio

Полная процедура — `docs/PORTFOLIO-SYNC.md`. Прочитать её целиком и пройти
по порядку: источники → сверка (классы А / Б / В) → проверка живого → правила
брифа → сборка → коммиты и пуш в `redesign` и `main` → отчёт в
`docs/sync/ГГГГ-ММ-ДД.md` и владельцу.

Главное:
- **Новую цифру без «да» владельца на сайт не ставить** — в отчёт вопросом.
- Объяснять владельцу по-русски, тексты сайта — по-английски.
- Коммиты без строки об авторстве ИИ.
